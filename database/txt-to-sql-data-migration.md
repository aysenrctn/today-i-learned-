# 📥 Data Engineering: Ingesting Flat Files (TXT) into SQL

During my internship, I executed a data ingestion task to parse structured raw text files (`.txt`) and load them directly into a relational SQL database.

### 🚀 Technical Execution
* **Schema Alignment:** Mapped raw text data delimiters (commas/tabs) to the target table's data types and constraints.
* **Bulk Ingestion:** Utilized database import tools and bulk insert scripts to streamline the transfer of flat file records.
* **Data Validation:** Verified row counts and data integrity post-ingestion to ensure no missing or corrupted records.

### 💡 Insight
Real-world data rarely starts in a pristine database; it often originates from legacy flat files or logs. Knowing how to efficiently parse and load raw text into SQL is an indispensable skill for data pipelines.
