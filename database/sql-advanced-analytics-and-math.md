# 🗄️ SQL Analytics: Advanced Aggregations, Math & Joins

Today, I solved complex data manipulation and spatial query problems on HackerRank to sharpen my SQL analytics skills.

### 🚀 Key Technical Concepts
* **Spatial & Mathematical Queries:** Calculated **Manhattan Distance** ($|x_1 - x_2| + |y_1 - y_2|$) and **Euclidean Distance** ($\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$) directly in SQL using `MAX()`, `MIN()`, `ABS()`, `POWER()`, and `SQRT()`.
* **String Manipulation & Pattern Matching:** Applied functions like `SUBSTR()` and `RIGHT()` to filter and format specific string patterns (e.g., retrieving first 3 / last 2 characters).
* **Aggregations & Sequences:** Practiced complex aggregation logic using `SUM()`, `COUNT()`, calculating differences between aggregate states, and working with `SEQUENCE` objects and `SYSDATE`.
* **Multi-Table Analytics:** Joined relational tables to consolidate multi-dimensional data sets.

### 💡 Insight
Calculating spatial geometries like Manhattan and Euclidean distances inside SQL reduces data transfer overhead by offloading mathematical computations directly to the database engine.
